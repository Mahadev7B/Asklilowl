# AskLilOwl submission packet

## Listing copy

**Name:** AskLilOwl

**Category:** Education

**Short description:** Turn explanations into interactive lessons and quizzes.

**Long description:** AskLilOwl renders complete, audience-aware lessons created in the active ChatGPT conversation as interactive slides with optional educational images, learning objectives, sources, and a comprehension quiz. ChatGPT performs any needed research and lesson writing; AskLilOwl validates and presents the result.

**Support:** https://asklilowl-chatgpt.onrender.com/support

**MCP endpoint:** https://asklilowl-chatgpt.onrender.com/mcp

## Starter prompts

1. Teach my child how birds fly with a short quiz.
2. Explain database indexes as an interactive lesson.
3. Research a current topic and teach it with sources.
